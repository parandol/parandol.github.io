持续改进中

TabDeck 最近更新

  1. v0.3.252026-11-19
    • Windows： TabDeck 已上架 Microsoft Store — 面板和 Android 应用中的 Windows 按钮会打开商店页面。
    • Linux： 如果缺少 TabDeck 需要的软件包（xdotool、ydotool、wl-clipboard、xdg-utils），启动时会询问是否安装，输入管理员密码后立即安装。X11 和 Wayland 均适用，支持 apt、dnf、zypper、pacman。
    • Linux： 如果选择了“稍后”，可随时通过托盘菜单中的“安装所需软件包…”进行安装。安装完成后 TabDeck 会重新连接，“缺少 xdotool”等警告将消失。
  2. v0.3.242026-11-18
    • Linux： 修复通过应用内更新重新启动后的 TabDeck 无法安装下一次更新的问题（"pkexec must be setuid root"）。
    • Linux： 在这种状态下更新时，会显示解决方法（退出后重新启动，或在终端运行 sudo apt install …），而不是直接报错。
  3. v0.3.232026-11-18
    • Linux（Wayland）： 通过 deb 安装时会一并安装键盘和鼠标输入所需的 ydotool、wl-clipboard 等，并自动让已登录用户可以使用输入设备（/dev/uinput）。如果 ydotoold 服务未运行，TabDeck 会自行启动它。
    • Linux： 应用自动更新也改为通过 apt 安装，所需软件包会一并安装。
    • 连接窗口： “复制地址”下方新增提示：“可直接在网页浏览器中控制。或 从应用商店安装 TabDeck 应用。”
