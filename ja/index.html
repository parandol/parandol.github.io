TabDeck · EJSOFT の代表製品

手持ちのタブレットが、PCのボタンパネルになります

ショートカット、アプリ起動、マクロ、メディア操作をワンタップで。使っているアプリに合わせてボタンが自動で切り替わり、トラックパッドやゲームパッドとしても使えます。

無料で始めるすべての端末向けダウンロード機能を詳しく見る →

PC アプリとタブレット・スマホのアプリを両方インストールしてください。

  • ✓すべての機能が無料・ボタン数の制限なし
  • ✓アカウント登録不要
  • ✓入力はローカルネットワーク内だけ

使うアプリごとに切り替わるボタン

アプリを切り替えると、ボタングループも自動で切り替わります。一度作れば、手が覚えます。

🎨

デザイン・動画編集

よく使うツールやショートカットをボタンに。ズームやスクロールはダイヤルを回して調整します。

💻

開発・ドキュメント作業

コードエディタ、ブラウザ、ビデオ会議 — 今前面にあるアプリのボタンだけを表示します。

🛋️

リビングのPC・プレゼン

タブレットをトラックパッドとメディアリモコンに。離れた場所から送り、止め、音量を下げられます。

🎮

ゲーム・マクロ

ゲームパッドモードで矢印キーを押し続け、複数の操作をまとめたマクロをワンタップで実行します。

3ステップで準備完了

  1. 1

    PC にアプリをインストール

    Windows・macOS・Linux 用の無料デスクトップアプリをインストールします。

  2. 2

    QR コードを読み取る

    PC 画面の QR コードをタブレットやスマホで読み取れば、すぐに接続されます。

  3. 3

    ボタンを押す

    最初はデフォルトのボタンで使い始め、必要な操作を追加して自分だけのパネルを作ります。

継続的に改善しています

TabDeck の最近のアップデート

  1. v0.3.262026-11-20
    • 接続: タブレットやスマートフォンの画面を再び点けると、パネルがすぐに再接続します。切れた接続は 3 秒以内に検出します。
    • パネル: スティック・ダイヤル・ゲームパッドの使用中に画面が更新されると、キーが押されたままになる問題を修正しました。接続が切れたときも、押されていたキーをすべて離します。
    • Android: 編集中にシステムの「戻る」を押すと、最初の画面へ出ずに 1 段階ずつ戻ります（ダイアログを閉じる → 上のフォルダ → 編集を終了）。Android 16 の「戻る」にも対応しました。
  2. v0.3.252026-11-19
    • Windows: TabDeck が Microsoft Store で公開されました — パネルと Android アプリの Windows ボタンからストアを開けます。
    • Linux: TabDeck に必要なパッケージ（xdotool、ydotool、wl-clipboard、xdg-utils）がない場合、起動時にインストールするか確認し、管理者パスワードを入力するとすぐにインストールします。X11・Wayland のどちらにも対応し、apt・dnf・zypper・pacman をサポートします。
    • Linux: 「後で」を選んだ場合も、トレイメニューの「必要なパッケージをインストール…」からいつでもインストールできます。インストール後は TabDeck が再接続され、「xdotool がありません」などの警告が消えます。
  3. v0.3.242026-11-18
    • Linux: アプリ内アップデートの後に再起動した TabDeck が次のアップデートをインストールできない問題（"pkexec must be setuid root"）を修正しました。
    • Linux: その状態でアップデートすると、エラーの代わりに対処方法（終了して再起動、またはターミナルで sudo apt install …）を表示します。

EJSOFT について

自分で使うために作ったツールを磨いて届ける、小さなソフトウェアスタジオです。大きな会社のようにたくさんは作れませんが、公開したアプリは長く改善し続けます。

  • 🔒
    必要なものだけを扱います

    アカウント不要。TabDeck の入力はサーバーを経由せず、ローカルネットワーク内の端末どうしでだけやり取りされます。

  • 🛠️
    報告された問題は直します

    いただいた問題を確認して修正し、何が変わったかを更新履歴ですべて公開しています。

  • 💬
    開発者が直接お答えします

    ストアのレビューや GitHub の提案は、アプリを作った本人が読んで直接お答えします。
