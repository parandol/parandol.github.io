TabDeck Manual

Everything in one place: installing and connecting TabDeck, editing buttons, automatic button group switching, mouse and gamepad modes, the Bluetooth keyboard and mouse, and which features work on which device.

About TabDeck

TabDeck turns the tablet or phone you already own into a button panel for your computer. Like a macro pad or stream deck, it runs shortcuts, launches apps, controls media and plays macros that chain several actions — each with a single tap. You can also use the whole screen as a trackpad or a gamepad.

How it fits together

PanelWhere you tapAndroid app · iPhone/iPad app · web browser
Wi-Fi (same network) →Bluetooth (keyboard/mouse) →
TargetWhat receives commandsWindows · macOS · Linux computers · an iPad paired over Bluetooth, etc.
  • TabDeck for computers (the desktop app) is the side that receives control. Install it on every computer you want to control; button layouts are stored on that computer.
  • The panel is where you tap. Open it in the tablet/phone app or a web browser.
  • One panel can switch between several computers, each with its own button layout. Several panels can connect to the same computer at once.
  • No account or sign-up is needed.

Installation

Computer app (free)

Windows

Search for "TabDeck" in the Microsoft Store and install it.

Get it from the Microsoft Store →

If a firewall prompt appears on first launch, allow private networks.

macOS

Download the .dmg for Apple silicon (arm64) or Intel (x64) from GitHub releases and move the app to Applications.

Download for macOS · Linux →

If macOS says it "cannot verify that it is free of malware", see Preparation by OS.

Linux

On Ubuntu/Debian, use the .deb — it installs the tools TabDeck needs. Otherwise use the .AppImage or .tar.gz.

sudo apt install ./TabDeck-<version>-linux-amd64.deb

Tablet · phone (panel)

Android

Install from Google Play. The Bluetooth keyboard and mouse feature is also in the Android app.

Get it on Google Play →

iPhone · iPad

The App Store app is coming soon. Until then, open the web panel in Safari.

Web browser

No install needed — open the address shown by the computer app in a browser. In iPad Safari, use Share → Add to Home Screen to open it full screen like an app.

Connecting

  1. Put the computer and the tablet/phone on the same Wi-Fi (network).
  2. Run TabDeck on the computer. Its window shows a QR code and a connection code.
  3. In the panel app, choose Add device → Scan QR code, or paste the connection code (IP:port#token).
  4. Once connected, the default button layout appears.

Several computers

  • Add other computers the same way with ＋ Add device.
  • Use the tabs at the top to switch devices. The dot shows the connection: green connected, yellow connecting, red offline.
  • Tap the name of the device you are controlling to change its name and grid size (columns × rows), or to disconnect.
Using a web browser? The device list is saved per address the browser opened, so always open the same address to keep it. On iPad, a Home Screen app and Safari tabs have separate storage — after adding to the Home Screen, add your devices again inside that app.

The computer app lives in the system tray (the menu bar on Mac). Closing the window keeps it running; quit from the tray menu. The computer app has no button panel and no ads.

Button panel

  • Top bar: device tabs, ＋ Add device, mode button, ⚙️ settings
  • Group bar: 🔄 Auto, group chips, ＋ Group, ✏️ Edit, and more
  • Mode button: each tap cycles button mode 🎛️ → mouse mode 🖱️ → gamepad mode 🎮. The button shows the icon of the next mode.
  • ⚙️ Settings: in the Android app it opens the app settings; in a browser it lets you pick the appearance (light/dark) and icon style.

Editing buttons

Tap ✏️ to enter edit mode. The screen is divided into cells, and each item can span as many cells as you like.

AddTap an empty cell (＋) to create an item there.
EditTap an item to open its editor. Tap the icon field to browse icons by category, type any emoji, or upload your own image.
MoveDrag an item; a dashed outline shows where it will land. An item already there moves to the nearest free cell. If there is no free cell, the outline turns red and you cannot drop.
ResizeDrag ◢ at the bottom right, or set the width and height in the editor.
Move to a folderChoose a folder under "Move to" in the editor to place the item in that folder's free cell.
Grid sizeTap the device name to change columns × rows. Items keep their positions.
Site iconA button that opens a web address without an icon uses the site's own icon. Use "Fetch site icon" in the editor to download it again.

Edits are saved on the target device and appear immediately on every other panel connected to it.

Item types

⚡ ButtonRuns an action when tapped.
📁 FolderOpens when tapped. Folders can contain folders (up to 8 levels).

Available actions depend on the device. Actions a device cannot run are grayed out or hidden in the editor. See features by target for details.

Hold a key while turning

Set "Key to hold while grabbing" on a dial and TabDeck presses that key (⌘, Alt, …) the moment you grab the dial and releases it when you let go. The app switch dial behaves exactly like holding ⌘+Tab and pressing Tab repeatedly. Keys are released automatically if the connection drops or nothing moves for 15 seconds.

App switch button

In a shortcut button's editor, tap 🔀 Fill as app switch button: Mac/iPad get ⌘+Tab, Windows/Linux get Alt+Tab, and Hold modifier briefly is turned on. One tap opens the app switcher; tap again within the set time (1 second by default) to move to the next app. Pair it with a ◀ Previous app button to go back and forth.

Button groups and auto switch

Besides the 🏠 Default group, each device can have as many groups as you like. Every group has its own layout, and when the front app on the target changes, the panel switches to that app's group automatically.

  1. In ✏️ edit mode, tap ＋ Group.
  2. Name it and pick a starting layout (blank, copy of the current screen, or a ready-made app layout).
  3. Under "When this app is in front", enter part of an app name or ID, one per line. ＋ Add the current front app fills it in for you.
  • 🔄 Auto: shows the group matching the front app, or the default group if none matches.
  • Group chip: tap to pin that group. Tap 🔄 Auto again to return to automatic switching.
  • Group buttons in edit mode: 📝 edit group info, ⧉ duplicate group, 🗑️ delete group (except the default group)

Auto switch with iPad Shortcuts

In the iPad Shortcuts app: Automation → ＋ → App → choose the app (e.g. Procreate), "Is Opened" → Run Immediately → add the action "Get Contents of URL" with the address copied from the group settings.

http://(Android device IP):7777/api/active-app?token=(token)&app=Procreate

To return to the default group when the app closes, add an "Is Closed" automation that sends a different name, such as app=Home.

Gamepad mode

🎮 Gamepad mode shows a D-pad (8 directions), A·B·X·Y, L·R and SELECT·START. Keyboard keys stay pressed for as long as you hold a button, which suits games and emulators.

Default keysD-pad = arrow keys, A=z B=x X=a Y=s L=q R=w SELECT=shift START=enter
Change keys⚙️ Gamepad key settings (saved per panel)

On targets that cannot hold keys down (direct Android control), gamepad mode is skipped and the panel returns to button mode. All held keys are released if the connection drops.

Bluetooth keyboard & mouse (Android)

For devices that cannot run the computer app, such as an iPad, the Android TabDeck app acts as a Bluetooth keyboard and mouse. For example, it can be a shortcut panel for Procreate on iPad. Nothing is installed on the receiving device.

  1. Open the Android app and allow the permissions (nearby devices, notifications).
  2. On the home screen, tap ＋ Add Bluetooth device → "Allow this device to be found".
  3. On the device you want to control (iPad, etc.), open Settings → Bluetooth and tap the Android device's name to pair.
  4. Tap 🔗 next to the device in the list to connect as a keyboard and mouse.
  5. Tap the device to open its button panel. You can also scan the QR code on the home screen from an iPhone or another tablet to control it from there (same Wi-Fi).
  • Default layout: a set of Procreate shortcuts (brush B, eraser E, undo ⌘Z, brush size [ ], …) with a brush size knob, an undo scrub knob and a trackpad.
  • Not available: opening apps, running commands and system actions cannot be done with keyboard and mouse signals. Text input is limited to English letters, numbers and symbols.
  • Modifier keys: the panel assumes a Bluetooth target is an Apple device and uses ⌘ as the default modifier. On Windows ⌘ arrives as the Windows key and on Android as the Meta key, so change buttons such as copy/paste to Ctrl combinations.
  • iPhone pointer: on iPhone, turn on Accessibility → AssistiveTouch to see the pointer.
  • Device limits: some Android devices block the Bluetooth keyboard feature in their manufacturer settings. The app shows a notice in that case.
  • iPhone/iPad app: iOS does not allow apps to act as a Bluetooth keyboard, so this feature is not available there.

Preparation by OS

macOS

Allow TabDeck under System Settings → Privacy & Security → Accessibility so keys and mouse input get through. The app window shows a guide and a button to open the setting.

If a warning appears the first time you open it, try opening it once, then click "Open Anyway" at the bottom of Privacy & Security. Or run this in Terminal:

xattr -dr com.apple.quarantine /Applications/TabDeck.app

If keys stop working after an update, remove TabDeck from the Accessibility list and add it again.

Windows

  • Allow private networks in the firewall prompt.
  • Keys cannot reach windows running as administrator (Task Manager, etc.). Run TabDeck as administrator to control them.
  • Ctrl+Alt+Del and Win+L are reserved by Windows and cannot be sent. To lock the screen, run the command rundll32.exe user32.dll,LockWorkStation.
  • "Open" takes a single program name or path. Use "Run command" when you need arguments.

Linux

X11 needs xdotool; Wayland needs ydotool 1.x and ydotoold (with /dev/uinput access). Non-English text on Wayland needs wl-copy (wl-clipboard). Installing the .deb sets all of this up.

sudo apt install ydotool wl-clipboard xdg-utils playerctl
sudo usermod -aG input $USER   # then sign in again

ydotool 0.1.8 on Ubuntu 24.04 and earlier does not work. Choosing the "Xorg" session on the login screen lets TabDeck work with xdotool alone. If you use ufw, open the port with sudo ufw allow 7777/tcp.

Android (being controlled)

Only the direct-install version can be controlled. Turn on the TabDeck service under Settings → Accessibility; without it only media keys and volume work.

Bluetooth receiving devices

Nothing to install — just pair over Bluetooth. Text is sent as English only, so set the receiving device's input to an English keyboard layout.

Ads and removing them

TabDeck is free. The mobile apps from Google Play and the App Store show a small banner ad; the computer app, the web browser panel and the direct-install app have no ads.

Monthly subscriptionNo ads while subscribed.
Lifetime licenseA one-time purchase that removes ads for good.
Buy the developer a coffeeNo ads for 3 months from the day of purchase.

Payments are handled by Google Play or the App Store. If you reinstalled the app or changed devices, tap Restore purchases on the purchase screen. You can also manage or cancel a subscription from there; it opens the store's subscription page.

Security and privacy

  • Button presses and keystrokes travel only between devices on your local network, never through a server.
  • Any device that knows the connection code (token) can control that computer. If "Allow running commands" is on, it can run commands too. Use TabDeck only on a Wi-Fi network you trust.
  • Traffic is not encrypted. Do not use it on public Wi-Fi.
  • If the connection code was exposed, tap Regenerate token in the computer app. Turn off running commands if you do not need it.

Troubleshooting

Scanning the QR code does not connect.

Make sure the computer and tablet are on the same Wi-Fi. Guest networks and routers with "AP isolation" turned on block devices from talking to each other. On Windows, allow TabDeck on private networks in the firewall; on Linux, open port 7777.

Nothing happens on my Mac when I tap a button.

Check that TabDeck is allowed under System Settings → Privacy & Security → Accessibility. After an update, remove TabDeck from the list and add it again.

Keys do not reach some windows on Windows.

Regular programs cannot send keys to windows running as administrator, such as Task Manager. Run TabDeck as administrator.

Text arrives garbled or as Korean letters.

Text sent over Bluetooth is English only. Switch the receiving device to an English keyboard layout. On Linux Wayland, install wl-clipboard for non-English text.

The button group does not change when I switch apps.

Check that 🔄 Auto is selected in the group bar; tapping a group chip pins that group. Linux Wayland and Bluetooth targets cannot report the front app, so auto switching does not work there (iPad can use a Shortcuts automation).

I cannot find gamepad mode.

Gamepad mode is hidden when the target cannot hold keys down (direct Android control).

Adding a Bluetooth device fails.

Some Android devices block the Bluetooth keyboard feature in the manufacturer settings. The app shows a notice in that case, and the Bluetooth feature cannot be used on that device.

My connection code was exposed.

Regenerate the connection token in the computer app settings. Every panel connected with the old code is disconnected and must connect again.

Ads came back after I removed them.

Tap "Restore purchases" on the purchase screen. Ads also return when a subscription expires or is refunded, or 3 months after a coffee purchase.
