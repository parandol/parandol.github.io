TabDeck 설명서

TabDeck을 설치하고 연결하는 방법부터 버튼 편집, 버튼 그룹 자동 전환, 마우스·게임패드 모드, 블루투스 키보드·마우스, 기기별로 되는 기능까지 한곳에 정리했습니다.

TabDeck 소개

TabDeck은 이미 가진 태블릿이나 휴대폰을 컴퓨터용 버튼 패널로 바꿔 주는 앱입니다. 매크로 패드나 스트림 덱처럼 단축키, 앱 실행, 미디어 조절, 여러 동작을 묶은 매크로를 버튼 하나로 실행합니다. 화면 전체를 트랙패드나 게임패드로 쓸 수도 있습니다.

구성

패널버튼을 누르는 쪽안드로이드 앱 · 아이폰/아이패드 앱 · 웹 브라우저
Wi-Fi (같은 네트워크) →블루투스 (키보드·마우스) →
제어 대상명령을 받는 쪽Windows · macOS · Linux 컴퓨터 · 블루투스로 연결한 아이패드 등
  • 컴퓨터용 TabDeck(데스크톱 앱)은 제어를 받는 쪽입니다. 조작할 컴퓨터마다 설치하며, 버튼 배치도 그 컴퓨터에 저장됩니다.
  • 패널은 버튼을 누르는 쪽입니다. 태블릿·휴대폰 앱이나 웹 브라우저에서 엽니다.
  • 패널 하나로 여러 컴퓨터를 오가며 제어할 수 있고, 컴퓨터마다 버튼 배치를 따로 만듭니다. 여러 패널을 한 컴퓨터에 동시에 연결할 수도 있습니다.
  • 계정이나 가입은 필요 없습니다.

설치

컴퓨터 앱 (무료)

Windows

Microsoft Store에서 "TabDeck"을 검색해 설치합니다.

Microsoft Store에서 받기 →

처음 실행할 때 방화벽 창이 뜨면 개인 네트워크 허용을 누릅니다.

macOS

GitHub 릴리스에서 Apple 실리콘(arm64) 또는 인텔(x64)용 .dmg를 받아 응용 프로그램 폴더로 옮깁니다.

macOS·Linux용 받기 →

처음 열 때 "악성 코드가 없음을 확인할 수 없습니다"가 나오면 준비 사항을 참고하세요.

Linux

우분투·데비안은 .deb를 권장합니다. 필요한 도구가 함께 설치됩니다. 그 밖에는 .AppImage나 .tar.gz를 씁니다.

sudo apt install ./TabDeck-<버전>-linux-amd64.deb

태블릿 · 휴대폰 (패널)

안드로이드

Google Play에서 설치합니다. 블루투스 키보드·마우스 기능도 안드로이드 앱에 있습니다.

Google Play에서 받기 →

아이폰 · 아이패드

App Store 앱을 준비하고 있습니다. 출시 전에는 Safari로 웹 패널을 열어 쓸 수 있습니다.

웹 브라우저

설치 없이 컴퓨터 앱이 보여 주는 주소를 브라우저로 열면 됩니다. 아이패드 Safari에서는 공유 → 홈 화면에 추가를 하면 전체 화면 앱처럼 열립니다.

연결하기

  1. 컴퓨터와 태블릿·휴대폰을 같은 Wi-Fi(네트워크)에 연결합니다.
  2. 컴퓨터에서 TabDeck을 실행하면 창에 QR 코드와 연결 코드가 나옵니다.
  3. 패널 앱에서 기기 추가 → QR 코드 스캔으로 QR을 찍거나, 연결 코드(IP:포트#토큰)를 붙여 넣습니다.
  4. 연결되면 바로 기본 버튼 배치가 나타납니다.

여러 컴퓨터 사용

  • 다른 컴퓨터도 같은 방법으로 ＋ 기기 추가를 눌러 추가합니다.
  • 위쪽 탭으로 제어할 기기를 바꿉니다. 점 색은 연결 상태입니다. 초록 연결됨, 노랑 연결 중, 빨강 오프라인.
  • 지금 제어 중인 기기 이름을 누르면 기기 이름, 칸 수(열×행), 연결 해제가 나옵니다.
웹 브라우저로 쓸 때 기기 목록은 브라우저가 연 주소별로 저장됩니다. 항상 같은 주소로 열어야 목록이 유지됩니다. 아이패드에서 홈 화면에 추가한 앱과 Safari 탭은 저장 공간이 달라서, 홈 화면에 추가한 뒤에는 기기를 그 앱에서 다시 추가해야 합니다.

컴퓨터 앱

컴퓨터 앱은 트레이(맥은 메뉴 막대) 아이콘으로 실행됩니다. 창을 닫아도 계속 실행되며, 종료는 트레이 메뉴에서 합니다. 컴퓨터 앱에는 버튼 패널이 없고 광고도 없습니다.

Microsoft Store로 설치한 앱은 스토어가 업데이트합니다. 그 밖에는 앱이 새 버전을 확인하고 설치 여부를 묻습니다.

버튼 패널 화면

  • 위쪽 막대: 기기 탭, ＋ 기기 추가, 모드 버튼, ⚙️ 설정
  • 그룹 막대: 🔄 자동, 그룹 칩, ＋ 그룹, ✏️ 편집 등
  • 모드 버튼: 누를 때마다 버튼 모드 🎛️ → 마우스 모드 🖱️ → 게임패드 모드 🎮 순서로 바뀝니다. 버튼에는 다음 모드의 아이콘이 보입니다.
  • ⚙️ 설정: 안드로이드 앱에서는 앱 환경설정을, 브라우저에서는 화면 모드(라이트·다크)와 아이콘 스타일 선택 창을 엽니다.

버튼 편집

✏️를 누르면 편집 모드가 됩니다. 화면은 칸으로 나뉘고, 각 항목은 원하는 만큼 여러 칸을 차지할 수 있습니다.

추가빈칸(＋)을 누르면 그 자리에 새 항목을 만듭니다.
편집항목을 누르면 편집 창이 열립니다. 아이콘 칸을 누르면 분류별 아이콘 목록이 열리고, 목록에 없는 이모지를 직접 입력하거나 내 이미지를 올릴 수도 있습니다.
이동항목을 끌면 놓일 자리가 점선으로 보입니다. 그 자리에 있던 항목은 가까운 빈자리로 옮겨지고, 빈자리가 없으면 빨간 점선이 되며 놓을 수 없습니다.
크기오른쪽 아래 ◢를 끌거나 편집 창의 너비·높이로 바꿉니다.
다른 폴더로편집 창의 "위치 이동"에서 폴더를 고르면 그 폴더의 빈자리로 옮깁니다.
칸 수기기 이름을 눌러 열×행을 바꿉니다. 칸 수를 바꿔도 항목 위치는 그대로입니다.
사이트 아이콘웹 주소를 여는 버튼에 아이콘이 없으면 그 사이트의 아이콘을 받아 씁니다. 편집 창의 "사이트 아이콘 가져오기"로 다시 받을 수 있습니다.

편집 내용은 제어 대상 기기에 저장되고, 같은 기기에 연결된 다른 패널에도 바로 반영됩니다.

키를 누른 채 돌리기

다이얼의 "잡고 있는 동안 누르고 있을 키"를 정하면, 다이얼을 잡는 순간 그 키(⌘, Alt 등)를 누르고 손을 떼는 순간 놓습니다. 앱 전환 다이얼은 실제로 ⌘+Tab을 누른 채 Tab을 여러 번 누르는 것과 같습니다. 연결이 끊기거나 15초 동안 움직임이 없으면 키를 자동으로 놓습니다.

앱 전환 버튼

단축키 버튼 편집 창의 🔀 앱 전환 버튼으로 채우기를 누르면 맥·아이패드는 ⌘+Tab, 윈도우·리눅스는 Alt+Tab이 들어가고 보조키 잠시 유지가 켜집니다. 한 번 누르면 앱 전환 화면이 뜨고, 정한 시간(기본 1초) 안에 다시 누르면 다음 앱으로 넘어갑니다. ◀ 이전 앱 버튼과 함께 쓰면 앞뒤로 오갈 수 있습니다.

버튼 그룹과 자동 전환

기기마다 🏠 기본 그룹 외에 원하는 만큼 그룹을 만들 수 있습니다. 그룹마다 버튼 배치가 따로 있고, 제어 대상에서 앞에 떠 있는 앱이 바뀌면 패널이 그 앱의 그룹으로 자동으로 바뀝니다.

  1. ✏️ 편집 모드에서 ＋ 그룹을 누릅니다.
  2. 이름을 정하고 시작 배치를 고릅니다(빈 화면, 현재 화면 복사, 준비된 앱별 배치).
  3. "이 앱이 앞에 있을 때"에 앱 이름이나 ID 일부를 한 줄에 하나씩 적습니다. ＋ 지금 앞에 있는 앱 추가를 누르면 자동으로 채워집니다.
  • 🔄 자동: 앞에 있는 앱에 맞는 그룹을 보여 줍니다. 맞는 그룹이 없으면 기본 그룹입니다.
  • 그룹 칩: 누르면 그 그룹에 고정됩니다. 다시 🔄 자동을 누르면 자동 전환으로 돌아갑니다.
  • 편집 모드의 그룹 버튼: 📝 그룹 정보 수정, ⧉ 그룹 복제, 🗑️ 그룹 삭제(기본 그룹 제외)

아이패드 단축어로 자동 전환

아이패드 단축어 앱 → 자동화 → ＋ → 앱 → 앱 선택(예: 프로크리에이트), "열릴 때" → 즉시 실행 → 동작 "URL 콘텐츠 가져오기"에 그룹 설정 창에서 복사한 주소를 넣습니다.

http://(안드로이드 기기 IP):7777/api/active-app?token=(토큰)&app=Procreate

게임패드 모드

🎮 게임패드 모드는 방향 패드(8방향), A·B·X·Y, L·R, SELECT·START 버튼을 보여 줍니다. 누르고 있는 동안 키보드 키를 계속 누른 상태로 보내므로 게임과 에뮬레이터에 맞습니다.

기본 키방향 패드 = 방향키, A=z B=x X=a Y=s L=q R=w SELECT=shift START=enter
키 바꾸기⚙️ 게임패드 키 설정 (패널마다 저장)

키를 누른 채 유지할 수 없는 대상(안드로이드 직접 제어)에서는 게임패드 모드가 빠지고 버튼 모드로 돌아갑니다. 연결이 끊기면 누르고 있던 키를 모두 놓습니다.

블루투스 키보드·마우스 (안드로이드)

아이패드처럼 컴퓨터 앱을 설치할 수 없는 기기는, 안드로이드 TabDeck 앱이 블루투스 키보드·마우스가 되어 조작합니다. 예를 들어 아이패드 프로크리에이트의 단축키 패널로 쓸 수 있습니다. 받는 기기에는 아무것도 설치하지 않습니다.

  1. 안드로이드 앱을 열고 권한(근처 기기, 알림)을 허용합니다.
  2. 첫 화면의 ＋ 블루투스 기기 추가 → "이 기기 찾기 허용"을 누릅니다.
  3. 조작할 기기(아이패드 등)의 설정 → 블루투스에서 안드로이드 기기 이름을 눌러 페어링합니다.
  4. 목록에 나타난 기기의 🔗를 누르면 키보드·마우스로 연결됩니다.
  5. 기기를 누르면 그 기기용 버튼 패널이 열립니다. 아이폰이나 다른 태블릿에서 첫 화면의 QR을 찍어 그 기기에서 조작할 수도 있습니다(같은 Wi-Fi).
  • 기본 배치: 프로크리에이트 단축키 묶음(브러시 B, 지우개 E, 실행 취소 ⌘Z, 브러시 크기 [ ] 등)과 브러시 크기 노브, 실행 취소 되감기 노브, 트랙패드가 들어 있습니다.
  • 쓸 수 없는 것: 앱 열기, 명령 실행, 시스템 동작은 키보드·마우스 신호로 할 수 없어 빠집니다. 텍스트 입력은 영문·숫자·기호만 됩니다.
  • 보조키: 패널은 블루투스 대상을 Apple 기기로 보고 ⌘를 기본 보조키로 씁니다. Windows에서는 ⌘가 Windows 키로, 안드로이드에서는 Meta 키로 들어가므로 복사·붙여넣기 같은 버튼은 Ctrl 조합으로 바꿔야 합니다.
  • 아이폰 마우스: 아이폰은 손쉬운 사용 → AssistiveTouch를 켜야 포인터가 보입니다.
  • 기종 제한: 일부 안드로이드 기기는 제조사 설정으로 블루투스 키보드 기능을 막아 둬서 쓸 수 없습니다. 이 경우 앱에 안내가 나옵니다.
  • 아이폰·아이패드 앱: iOS는 블루투스 키보드 역할을 허용하지 않아 이 기능이 없습니다.

운영체제별 준비 사항

macOS

시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 TabDeck을 허용해야 키·마우스가 전달됩니다. 앱 창에 안내와 설정 열기 버튼이 나옵니다.

처음 열 때 경고가 나오면 한 번 열기를 시도한 뒤 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누릅니다. 또는 터미널에서 다음을 실행합니다.

xattr -dr com.apple.quarantine /Applications/TabDeck.app

업데이트 뒤 키 입력이 안 되면 손쉬운 사용 목록에서 TabDeck을 지웠다가 다시 추가하세요.

Windows

  • 방화벽 창에서 개인 네트워크를 허용합니다.
  • 관리자 권한 창(작업 관리자 등)에는 키 입력이 막힙니다. 그런 창도 제어하려면 TabDeck을 관리자 권한으로 실행합니다.
  • Ctrl+Alt+Del, Win+L은 윈도우가 막아 둔 조합이라 보낼 수 없습니다. 화면 잠금은 명령 rundll32.exe user32.dll,LockWorkStation을 씁니다.
  • "열기"에는 프로그램 이름이나 경로 하나만 넣습니다. 인자가 필요하면 "명령 실행"을 씁니다.

Linux

X11은 xdotool, Wayland는 ydotool 1.x와 ydotoold(/dev/uinput 권한)가 필요합니다. Wayland에서 한글 입력은 wl-copy(wl-clipboard)가 있어야 합니다. .deb로 설치하면 함께 준비됩니다.

sudo apt install ydotool wl-clipboard xdg-utils playerctl
sudo usermod -aG input $USER   # 다시 로그인

우분투 24.04 이하의 ydotool(0.1.8)은 동작하지 않습니다. 로그인 화면에서 "Xorg" 세션을 고르면 xdotool만으로 동작합니다. 방화벽(ufw)을 쓰면 sudo ufw allow 7777/tcp로 포트를 엽니다.

안드로이드 (제어받는 쪽)

직접 설치판만 가능합니다. 설정 → 접근성에서 TabDeck 서비스를 켜야 하며, 꺼져 있으면 미디어 키·볼륨만 동작합니다.

블루투스로 받는 기기

설치할 것은 없고 블루투스 페어링만 하면 됩니다. 텍스트 입력은 영문만 보내므로 받는 쪽 입력 언어를 영어 자판으로 두어야 합니다.

광고와 광고 제거

TabDeck은 무료입니다. Google Play·App Store에서 받은 모바일 앱에는 작은 배너 광고가 있고, 컴퓨터 앱·웹 브라우저 패널·직접 설치판에는 광고가 없습니다.

월 구독구독하는 동안 광고가 나오지 않습니다.
평생 이용권한 번 구매하면 계속 광고가 나오지 않습니다.
개발자에게 커피 보내기결제한 날부터 3개월 동안 광고가 나오지 않습니다.

결제는 Google Play 또는 App Store가 처리합니다. 앱을 다시 설치했거나 기기를 바꿨다면 구매 화면의 구매 복원을 누르세요. 구독 관리·취소도 구매 화면에서 스토어 구독 페이지로 이동해 합니다.

보안과 개인정보

  • 버튼과 키 입력은 같은 네트워크의 기기끼리만 오가며 서버를 거치지 않습니다.
  • 연결 코드(토큰)를 아는 기기는 그 컴퓨터를 조작할 수 있습니다. "명령 실행 허용"이 켜져 있으면 명령도 실행할 수 있습니다. 신뢰할 수 있는 Wi-Fi에서만 쓰세요.
  • 통신은 암호화되지 않습니다. 공용 Wi-Fi에서는 쓰지 마세요.
  • 연결 코드가 노출됐다면 컴퓨터 앱에서 연결 토큰 재생성을 누릅니다. 명령 실행이 필요 없으면 꺼 두세요.

문제 해결

QR 코드를 찍어도 연결되지 않아요.

컴퓨터와 태블릿이 같은 Wi-Fi에 있는지 확인하세요. 게스트 네트워크나 공유기의 "AP 격리" 기능이 켜져 있으면 기기끼리 통신할 수 없습니다. Windows는 방화벽에서 TabDeck의 개인 네트워크 허용, Linux는 7777 포트 허용이 필요합니다.

맥에서 버튼을 눌러도 아무 일도 일어나지 않아요.

시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 TabDeck을 허용했는지 확인하세요. 업데이트 뒤라면 목록에서 TabDeck을 지웠다가 다시 추가하세요.

윈도우의 일부 창에서만 키가 안 먹어요.

작업 관리자처럼 관리자 권한으로 실행된 창에는 일반 프로그램이 키를 보낼 수 없습니다. TabDeck을 관리자 권한으로 실행하세요.

한글 텍스트가 깨지거나 영문 자모로 입력돼요.

블루투스로 보내는 텍스트는 영문만 됩니다. 받는 기기의 입력 언어를 영어 자판으로 바꾸세요. Linux Wayland에서는 wl-clipboard를 설치해야 한글이 입력됩니다.

앱을 바꿔도 버튼 그룹이 자동으로 바뀌지 않아요.

그룹 막대에서 🔄 자동이 선택되어 있는지 확인하세요. 그룹 칩을 누르면 그 그룹에 고정됩니다. Linux Wayland와 블루투스로 연결한 기기는 앞에 있는 앱을 알 수 없어 자동 전환이 되지 않습니다(아이패드는 단축어 자동화로 가능).

게임패드 모드가 보이지 않아요.

키를 누른 채 유지할 수 없는 대상(안드로이드 직접 제어)에 연결되어 있으면 게임패드 모드가 빠집니다.

블루투스 기기 추가가 안 돼요.

일부 안드로이드 기기는 제조사 설정으로 블루투스 키보드 기능을 막아 둡니다. 이 경우 앱에 안내가 나오며, 그 기기로는 블루투스 기능을 쓸 수 없습니다.

연결 코드가 다른 사람에게 노출됐어요.

컴퓨터 앱의 환경설정에서 연결 토큰을 재생성하세요. 이전 코드로 연결된 패널은 모두 끊기고 다시 연결해야 합니다.

광고 제거를 샀는데 광고가 다시 나와요.

구매 화면의 "구매 복원"을 누르세요. 구독이 만료되었거나 환불된 경우, 커피 구매 후 3개월이 지난 경우에는 광고가 다시 나옵니다.
