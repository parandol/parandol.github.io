태블릿을 컴퓨터의 버튼 패널로

이미 가진 태블릿이나 휴대폰을 매크로 패드, 스트림 덱처럼. 단축키·앱 실행·미디어 조절을 한 번에 누르세요.

  • QR 코드 한 번으로 연결 · 계정 필요 없음
  • 지금 쓰는 앱에 맞춰 버튼이 자동 전환
  • 트랙패드 · 게임패드 · 블루투스 키보드 모드

몇 초 만에 연결

같은 Wi-Fi에 있는 컴퓨터와 태블릿이면 준비 끝입니다.

  1. 1

    컴퓨터 앱 설치

    Windows·macOS·Linux 컴퓨터에 무료 TabDeck 데스크톱 앱을 설치합니다.

  2. 2

    QR 코드 스캔

    컴퓨터 화면에 나온 QR 코드를 태블릿이나 휴대폰으로 찍습니다.

  3. 3

    버튼 누르기

    복사·붙여넣기, 화면 캡처, 앱 실행까지 원하는 동작을 한 번에.

핵심 기능

⌨️

단축키 버튼

복사, 붙여넣기, 실행 취소, 화면 캡처와 직접 만든 단축키를 버튼 하나로.

🚀

앱 · 웹사이트 실행

자주 쓰는 앱과 웹 주소를 버튼에 담아 바로 엽니다.

🎚️

다이얼 · 미디어

확대·음량·스크롤용 다이얼과 재생·음량 조절 버튼.

🔗

매크로

여러 동작을 묶어 한 번에 실행합니다. 폴더와 자유로운 버튼 크기도 지원.

🔄

앱별 자동 전환

포토샵, 코드 편집기, 화상 회의 — 지금 쓰는 앱에 맞춰 버튼 그룹이 바뀝니다.

🖱️

마우스 · 게임패드

화면 전체를 트랙패드로, 또는 방향키·문자 키를 누르고 있는 게임패드로.

📶

블루투스 키보드·마우스

안드로이드에서는 컴퓨터 앱 없이도 아이패드 등에 블루투스로 키를 보냅니다.

🖥️

여러 기기 동시 연결

태블릿 여러 대를 함께 쓰고, 컴퓨터 사이를 오가며 사용합니다.

컴퓨터 (무료)

조작할 컴퓨터에 설치합니다. 광고가 없습니다.

WindowsMicrosoft StoreGitHubmacOS · Linux

TabDeck은 무료이며 모바일 앱의 버튼 패널 상단에 작은 배너 광고가 있습니다. 월 구독이나 평생 이용권으로 광고를 없앨 수 있고, 개발자에게 커피 한 잔을 보내면 3개월 동안 광고가 나오지 않습니다.

🔒

입력은 내 네트워크 안에서만

버튼과 키 입력은 같은 네트워크의 기기끼리만 오가며 서버를 거치지 않습니다. 연결 코드를 아는 기기만 컴퓨터를 조작할 수 있고, 계정도 필요 없습니다.

업데이트 기록

최근 버전에서 바뀐 점입니다. 컴퓨터 앱은 새 버전이 나오면 알려 줍니다.

  1. v0.3.252026-11-19
    • Windows: Microsoft Store에 정식 등록되었습니다.
    • Linux: 필요한 패키지가 없으면 시작할 때 바로 설치해 줍니다(apt·dnf·zypper·pacman).
    • Android: 블루투스 기기가 없는데 패널에 기기가 추가되던 문제, Android 15 이상에서 화면 위아래가 가리던 문제를 고쳤습니다.
  2. v0.3.242026-11-18
    • Linux: 앱 안에서 업데이트한 뒤 다음 업데이트가 설치되지 않던 문제를 고쳤습니다.
  3. v0.3.232026-11-18
    • Linux(Wayland): deb로 설치하면 키보드·마우스 입력에 필요한 도구와 권한이 자동으로 설정됩니다.
    • 연결 창: 웹 브라우저에서 바로 제어할 수 있다는 안내를 넣었습니다.
  4. v0.3.222026-11-18
    • 데스크톱 앱이 GitHub 최신 릴리스에서 업데이트를 받습니다.
    • Windows·Linux: 앱 아이콘이 기본 아이콘으로 보이던 문제를 고쳤습니다.
  5. v0.3.212026-11-18
    • 데스크톱: 연결 QR 코드 아래에 스토어 설치 버튼과 설치용 QR 코드를 넣었습니다.
    • Android: 연결 중에는 알림을 띄워 연결이 끊기지 않게 합니다.
